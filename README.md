What is this project?

This is a Power BI-based project monitoring dashboard designed for infrastructure/construction projects.

The purpose is to allow management to monitor:

Project milestones
Resource allocation
Delivery/progress metrics
Delays
Project performance
Resource requirements

The resume states that the solution used Power BI, Alteryx, and Advanced Excel.

Simple real-world example

Imagine a company has 20 construction projects:

Project	Location	Planned %	Actual %	Resources	Status
Project A	Delhi	80%	75%	25	Delayed
Project B	Noida	60%	65%	15	On Track
Project C	Gurgaon	90%	82%	30	Delayed

Instead of management opening multiple Excel files, the Power BI dashboard brings everything together.

Why Alteryx?

Alteryx can be used before Power BI to:

Raw Data
   ↓
Remove duplicates
   ↓
Clean missing values
   ↓
Join datasets
   ↓
Calculate fields
   ↓
Output clean dataset
